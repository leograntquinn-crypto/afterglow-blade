# 残光之刃 · Afterglow Blade

原创横版 2.5D 动作游戏。纯 HTML5 Canvas + 原生 JavaScript，不依赖任何框架和图片素材。

## 运行

```bash
cd game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> ES 模块（`import`）必须通过 http 访问，直接双击 index.html 打不开。

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 移动（W/S 是纵深方向） |
| J | 攻击，连按三连斩 |
| W + J | 上挑：把敌人打上天 → 按 K 跳起来追打 |
| K | 跳跃（空中可以 J 两段空中斩，第二段把敌人砸地反弹） |
| L | 闪避，前 14 帧无敌；闪避中按 J 是冲刺攻击 |
| U / I / O / P | 技能：裂空斩 / 回风斩 / 崩山击 / 千刃·残光（3、6、10 级解锁）。普攻打中后可立刻用技能取消 |
| Esc | 暂停，可以撤退回营地（保留收获） |

## 代码结构

```
src/
  main.js     主循环（固定 60 帧/秒）、场景切换、伤害计算、命中处理、掉落与拾取
  config.js   常量、2.5D 坐标换算
  input.js    键盘 + 触屏 → 统一的「动作」，带输入缓冲
  moves.js    ★ 招式帧数据表：调手感就改这里
  player.js   主角状态机、招式执行、取消系统
  enemy.js    敌人类型表、AI、受击反应（硬直/浮空/倒地/霸体）
  combat.js   判定框、飞行道具、地面范围攻击
  fx.js       火花、刀光、伤害数字、震屏、闪屏
  draw.js     背景场景、阴影、暗角
  hud.js      血条、技能栏、连击、标题/结算画面
  stages.js   5 个关卡的波次配置与评价算法
  progression.js ★ 成长系统：经验曲线、属性点、技能树、computeStats()
  items.js    装备：品质、随机词条、强化、出售
  loot.js     掉落物（品质光柱、金币）
  save.js     存档：本地 + 云端同步
  hub.js      营地界面（HTML）：出征 / 角色 / 技能
  rig.js      ★ 角色建模：2D 骨骼 + IK + 描边分层着色
model-sheet.html  模型展示页：一次看所有角色和姿势，改建模时用
```

## 这一版涉及的核心概念

1. **固定时间步长**：逻辑永远每秒 60 次，与显示器刷新率无关（`main.js` 底部）。
2. **状态机**：角色同一时刻只有一个状态，每个状态只管自己（`player.js` 顶部的图）。
3. **帧数据驱动**：起手、判定、收招都是数字，策划改表不改代码（`moves.js`）。
4. **取消系统**：招式到某一帧后可以接下一招，这是连招的本质（`updateMove`）。
5. **输入缓冲**：提前按的键会被记住约 10 帧，避免「吃键」（`input.js`）。
6. **打击感五件套**：顿帧、震屏、火花、伤害数字、音效（`applyHit`）。
7. **公平的 AI**：出招前有预警，同一时间最多 2 个敌人进攻（攻击令牌）。
8. **霸体与破防**：铁甲屠夫要先打掉护甲条才能连招，并且能打断它的砸地。

## 成长系统（M2）涉及的概念

1. **单一数据源**：所有成长（等级、属性点、装备、技能）都汇总到 `computeStats()`，战斗代码只读结果。
2. **伤害公式**：`招式伤害 × 攻击力/20 × 技能或普攻加成 × 暴击`；敌人打你时 `× 100/(100+防御)`。
3. **随机词条**：品质决定词条数量（0~3），物品等级决定数值范围（`items.js`）。
4. **加权随机**：掉落品质按权重抽取，关卡越深、精英越多，高品质概率越高（`rollRarity`）。
5. **技能等级上限**：`1 + 角色等级 - 解锁等级`，防止前期把点数全部堆在一个技能上。
6. **装备驱动外观**：武器类型和品质决定刀的形状和光色，刀光、剑气也跟着变色。
7. **IK 反向动力学**：只给手脚「目标点」，膝盖和手肘的位置自动算出来（`rig.js` 的 `ik()`）。
8. **存档同步**：本地立即保存；云端按 `savedAt` 时间戳比较新旧，写入请求串行发送。

## 调试小技巧

打开浏览器控制台（F12）：

```js
__game.player.hp = 9999       // 无敌
__game.player.cd.skill3 = 0   // 立刻冷却
__game.save.gold += 99999     // 加金币（回营地后刷新显示）
```
