# 残光之刃 · Afterglow Blade

原创横版 2.5D 动作游戏。纯 HTML5 Canvas + 原生 JavaScript，不依赖任何框架。

主角「绯隼」、三种敌人（腐骨兵、铁甲屠夫、影弓手）和两个首领（骸骨领主、祭坛守护者）都是逐帧手绘精灵；另外三个首领暂时用敌人精灵放大染色。场景是手绘的地宫套件 + 每关一张远景 + 手绘道具（`assets/env/`、`assets/props/`），光照、火焰、雾和粒子由引擎实时画。特效是手绘贴图和序列帧（`assets/fx/`）+ 引擎的粒子、演出和 WebGL 后处理。素材来源见各 `assets/*/ATTRIBUTION.md`，用 `tools/build_sprites.py`（角色、道具）、`tools/build_env.py`（环境）和 `tools/build_fx.py`（特效）处理。美术规格和生成提示词在 `docs/ART_FEISUN.md`（主角）、`docs/ART_ENEMIES.md`（敌人）、`docs/ART_V4.md`（首领、技能动作、环境、道具）和 `docs/ART_FX.md`（特效）。

## 运行

```bash
cd game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> ES 模块（`import`）必须通过 http 访问，直接双击 index.html 打不开。

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 移动（W/S 是纵深方向） |
| J | 攻击，连按三连斩；二段斩后停顿一拍再按 = 五连刺 |
| 按住 J | 蓄力斩（两段，满蓄力为「破军」，可撞墙） |
| W + J / S + J | 上挑浮空 / 扫腿（可追打倒地） |
| 命中后 K | 跳跃取消，追到空中继续连 |
| 空中 J J J / 空中 S + J | 空中三连（砸地反弹）/ 坠星斩（落地冲击波） |
| L / 空中 L | 闪避 / 空中冲刺。攻击命中前一瞬闪避 = 极限闪避（子弹时间 + 反击必暴击） |
| 对刀 | 敌人近战命中的瞬间面朝它出刀 = 弹刀（敌人长硬直，霸体被打破） |
| 被打飞时 K / 倒地时任意键 | 受身 / 快速翻滚起身 |
| H | 残光槽满：必杀「残光·终焉」 |
| U / I / O / P | 技能：裂空斩 / 回风斩 / 崩山击 / 千刃·残光（3、6、10 级解锁）。普攻打中后可立刻用技能取消 |
| Esc | 暂停，可以撤退回营地（保留收获） |
| M | 开关背景音乐 |

## 这一版涉及的核心概念

1. **固定时间步长**：逻辑永远每秒 60 次，与显示器刷新率无关（`main.js` 底部）。
2. **状态机**：角色同一时刻只有一个状态，每个状态只管自己（`player.js` 顶部的图）。
3. **帧数据驱动**：起手、判定、收招都是数字，策划改表不改代码（`moves.js`）。
4. **取消系统**：招式到某一帧后可以接下一招，这是连招的本质（`updateMove`）。
5. **输入缓冲**：提前按的键会被记住约 10 帧，避免「吃键」（`input.js`）。
6. **打击感五件套**：顿帧、震屏、火花、伤害数字、音效（`applyHit`）。
7. **公平的 AI**：出招前有预警，同一时间最多 2 个敌人进攻（攻击令牌）。
8. **霸体与破防**：铁甲屠夫要先打掉护甲条才能连招，并且能打断它的砸地。

## 成长系统（M2）涉及的概念

1. **单一数据源**：所有成长（等级、属性点、装备、技能）都汇总到 `computeStats()`，战斗代码只读结果。
2. **伤害公式**：`招式伤害 × 攻击力/20 × 技能或普攻加成 × 暴击`；敌人打你时 `× 100/(100+防御)`。
3. **随机词条**：品质决定词条数量（0~3），物品等级决定数值范围（`items.js`）。
4. **加权随机**：掉落品质按权重抽取，关卡越深、精英越多，高品质概率越高（`rollRarity`）。
5. **技能等级上限**：`1 + 角色等级 - 解锁等级`，防止前期把点数全部堆在一个技能上。
6. **装备驱动外观**：武器类型和品质决定刀的形状和光色，刀光、剑气也跟着变色。
7. **IK 反向动力学**：只给手脚「目标点」，膝盖和手肘的位置自动算出来（`rig.js` 的 `ik()`）。
8. **存档同步**：本地立即保存；云端按 `savedAt` 时间戳比较新旧，写入请求串行发送。

## 地下城与首领（M5）涉及的概念

1. **程序化生成**：每次出征随机生成地图；主线保证能走到首领，支线是可选的奖励房间（`dungeon.js`）。
2. **招式库 + 配置**：首领的招式写成可复用的「库」，每个首领只是一份配置：用哪些招式、权重多少、几个阶段。
3. **公平的难度**：每一招都有预警（红光、感叹号、地面红圈/红带），玩家看得懂才躲得开。
4. **阶段转换**：血量阈值触发咆哮、霸体回满、出招加快、招式表切换。

## 画面精修涉及的概念

1. **离屏缓存**：砖墙、地砖这类纹理只在启动时画一次，之后每帧 `drawImage`（`scenery.js`）。
2. **多层视差**：远景 0.3 倍速、后墙 0.9 倍速、地面切成细条按纵深 0.88~1.18 倍速、前景 1.35 倍速，营造纵深。
   手绘环境是中性灰，每关的色调由引擎用「乘色」整体染上；火把台是画好的空台，火焰和光源由引擎画在台上。
3. **光照图**：先铺满黑暗，再在光源处用 `destination-out`「挖洞」（`post.js`）。
4. **泛光**：发光物体再画一份，缩小再放大（廉价模糊），叠加上去。
5. **自适应画质**：持续掉帧时自动降低渲染分辨率、关闭部分特效。
6. **特效的质感**：锐利的芯（针芒）+ 柔和的光晕 + 颜色随寿命从白热到本色再变暗 + 一部分余烬留在画面里慢慢飘散；烟和碎片用普通混合，光用叠加混合。
   粒子对象全部预先分配、用完回收，战斗中不产生垃圾；画质越低粒子越少（`fx.lod`）。
   受击分级（`HIT_TIERS`）：轻击 < 暴击 < 重击 < 破招 / 破防 < 击杀，越重的一击星芒、冲击线、斩痕、镜头后坐越强；同一帧打中多个敌人时只有第一下给全套，避免叠成一片白。
   刀光是一条连续的光带：外圈柔光、按年龄变色的主体、外沿亮边、白芯，刀尖甩出细碎光点。
   技能三拍（`cine.js` + 各招式事件）：蓄力时世界压暗、只留主角身边一圈光、集中线收拢、地面光圈往脚下收；爆发时集中线炸开、地面冲击波、冲天光柱、星芒；余韵是残光从地面升起慢慢飘散，压暗缓缓退去。
   WebGL 后处理（`glpost.js`）：世界画完、画 HUD 之前把这一帧交给着色器 —— 冲击波把背景往外推（`fx.shock`）、重击时红蓝通道错开（`fx.aberrate`）、高斯泛光、高光肩部压缩（叠加发光不再一片死白）。
   画质 2：两级泛光 + 扭曲 + 色差 + 颗粒；画质 1：一级泛光 + 扭曲；画质 0、浏览器不支持、着色器编译失败、上下文丢失：自动退回 Canvas 后处理。地址加 `?nogl` 可以强制走 Canvas。
   手绘特效素材（`docs/ART_FX.md`）：烟、尘爆、碎片、地裂、冲击环、星芒、光柱、符文圈是手绘贴图（替换程序占位，按占位的可见大小换算，原有特效大小不变）；
   刀光、命中爆点、地面爆发、能量爆发、滚烟、残光爆散、骨刺、骨裂斩痕、魂火、召唤法阵是手绘序列帧，叠在程序特效上播放。灰度素材，引擎按刀光 / 关卡 / 首领颜色染色。
   首领：出招预警时脚下红圈收缩、红光往身上聚；身上不断飘起的气（阶段越高越密）；倒下时化成光点消散。
7. **性能陷阱**：`shadowBlur` 会对每一笔绘制都做模糊，非常慢；改用渐变光晕代替。
8. **按需载入**：首领图集和每关远景只在那一关载入、离开就释放；手机读 75% 格子的角色图集和 1 倍环境图，解码后的内存约为桌面的一半。
9. **程序化音乐**：Web Audio 提前预约音符（look-ahead scheduling），按战况淡入淡出不同声部。

## 战斗内核

- **进攻路线**：地面连段、延迟连段、蓄力两段、扫腿、上挑 → 跳跃取消 → 空中三连 → 坠星斩 → 追打倒地，技能和必杀可以随时取消普攻
- **防守回报**：极限闪避 → 子弹时间（敌人 1/4 速）+ 170 帧反击必暴击；弹刀 → 敌人长硬直、破霸体
- **受击物理**：撞墙反弹、被打飞的敌人撞倒同伴（弹球，可以连锁）、砸地反弹、追打倒地（每次倒地一次）、连续浮空越落越快
- **风格评价 D → SSS**：同一招反复用分数递减，空中、追打、反击、弹刀、撞墙加分；受伤掉两级；评级越高敌人进攻越凶
- **残光槽**：命中、击杀、受伤、极限闪避、弹刀都会充能，满了放全屏必杀（敌人定格，瞬身连斩 + 终结一击）
- **反馈**：材质碎片（骨渣/布屑/金属屑）、受击挤压、镜头朝命中方向推、重击推近、刀光颜色随武器品质
- **破招**：敌人出招预警（红光）时抢先打中它 → 打断招式、伤害 +50%、硬直 ×1.6、技能冷却回转。霸体敌人要用重击 / 浮空招式才能打断，普攻只削霸体 ×3；首领预警时破招削霸体 ×2.5。和「等它打过来再闪避 / 弹刀」形成两条路：预判抢攻，还是反应防守
- **冷却回转**：破招、极限闪避、弹刀成功时，所有技能冷却 -1.5 秒（长剑 -3 秒），技能栏会扫过一道橙光
- **首领读条**：每个首领从第二阶段起会读条大招（各有名字），脚下红圈慢慢铺满全场。读条结束前打满打断值（普攻 +1、重击 / 技能 +2、必杀 +4，或者把霸体削空）→ 首领倒地破防 4 秒；没打断就跳起来或极限闪避躲开
- **武器流派**：长剑「游刃」冷却回转翻倍（预判流），太刀「疾斩」取消窗口提前 3 帧（手速流），巨剑「崩山」削霸体 ×1.6、普攻也能破招打断霸体（破甲流）。装备详情里能看到
- **战意**：击杀时的风格评级决定战利品（C +10% … SSS +100%：经验、金币、掉装备概率和品质）。风格字母下方显示当前加成；挨一下打评级掉两级，加成跟着掉
- **刻印**：稀有装备 40%、传说装备必带一条刻印，在你做到某件事时生效（断势：破招后暴击；凌空：打空中敌人；残心：极限闪避后技能；无瑕：满血；背水：残血；追魂：追打倒地；震壁：撞墙后；连锋：长连击）。同名不叠加，角色面板列出已激活的刻印
- **复盘**：死亡画面列出致命一击、受伤最多的三种攻击、出招中被打中的比例和一条针对性建议；通关画面在最弱的评价项给提升建议
- **委托与铭刻**（`src/contracts.js`）：营地出征页顶上 3 张委托（破招、无伤清房、通关某关某难度、换某种武器通关……），出征中累计进度，完成后领取刻印石和金币；领过的格子第二天补上，没完成的不过期，每天可免费换一张。刻印石用来给稀有 / 传说装备铭刻指定的刻印
- **残光试炼**（`src/trial.js`）：通关第一关解锁。一层一个房间，层数就是敌人等级，词缀和精英越来越多，每 5 层轮换一个首领；每过一层回 20% 生命，并选择继续还是带着奖励离开（J 继续 / L 离开）。奖励池：每层金币、每个首领层 1 颗刻印石；离开拿全部，阵亡只拿一半；最高层数记为个人纪录
- **装备生态**：传承（新装备付金币继承同部位旧装备的强化等级，约为重新强化的 35%）、重铸（花金币把一条词条换成另一种属性，每次贵 50%）、锁定、批量出售（普通 / 精良及以下，跳过锁定、强化过和带刻印的）
- **设置与无障碍**（`src/settings.js`）：营地顶部和暂停菜单都能打开。震屏强度、闪屏与冲击帧开关（对光敏感时建议关闭）、重击镜头推近、伤害数字（全部 / 只看暴击 / 关）、音效与音乐音量、触屏按钮大小；保存在本机
- **精英词缀**（`src/affix.js`）：精英怪带 1～2 条词缀，每条逼你换一种打法
  - 坚盾：正面挡住普通攻击、转身慢 → 等它出招后的空隙、冲刺绕背，或用重击 / 上挑 / 弹刀破盾
  - 狂暴：血量过半后移动和出招变快 → 留好爆发收尾
  - 迅影：连续挨 7 下就瞬移到你背后反击 → 连段别贪，看到紫光就闪避
  - 爆裂：死后原地爆炸 → 离开红圈；爆炸也会炸到别的敌人，可以拿来清场
- **难度**（`src/stages.js` 的 `DIFFS`）：通关一个关卡的普通难度，解锁它的「噩梦」；通关噩梦解锁「地狱」。高难度关卡等级 +5 / +10，敌人血量和伤害再乘 1.3 / 1.6 倍、预警时间缩短到 86% / 74%、同时进攻的敌人多 1 个、精英多带 1 / 2 条词缀、普通怪 30% / 55% 带词缀；奖励经验金币 ×1.3 / ×1.6，掉落品质更好，地狱首领必掉一件传说。每个难度分别记录通关和最佳评价，各有一次首通 ×3 奖励
- **训练场**（`src/training.js`）：营地「出征」页第一张卡片。两个打不死的木人（右边那个靠墙，练撞墙）+ 14 条挑战，每个机制做到一次就打勾，第一次完成有金币。按 T 让木人反击（练极限闪避、弹刀、受身），R 重置木人，面板上实时显示每秒伤害和单次连击最高伤害
