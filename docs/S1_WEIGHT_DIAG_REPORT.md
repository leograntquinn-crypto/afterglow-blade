# P0 诊断报告：run 时手-大腿粘连归因（feisun_s1.glb，已入库版）

日期：2026-11-25 夜。方法：Fable《3D_MODEL_AND_FEEL_GUIDE》①.2——权重普查 + 杠杆扫描 + run 全周期间距曲线 + 自然速度实测。对象：游戏内实际使用的 `art/models/feisun_s1.glb`（182,552 顶点 / 58 骨 / run 片段 31 帧 @24fps）。原始数据：`weight_audit.csv`、`lever_scan.csv`、`run_clearance.csv`（本目录）。

## 结论：A 类权重串扰，坐实。主方向是「手臂骨拖大腿顶点」。

### 证据 1 — 杠杆扫描（决定性）
静止姿势下单独旋转一根骨 0.6 rad，看异区探针位移（合格线 < 1 mm）：

| 旋转骨 | 被拖动区域 | 最大位移 | 判定 |
|---|---|---|---|
| L_Upperarm | 左大腿顶点 | **110.4 mm** | FAIL（110 倍于合格线） |
| R_Upperarm | 右大腿顶点 | **104.3 mm** | FAIL |
| L_Forearm | 左大腿顶点 | **68.8 mm** | FAIL |
| R_Forearm | 右大腿顶点 | **59.0 mm** | FAIL |
| R_Thigh | 右手/前臂顶点 | 14.3 mm | FAIL |
| L_Thigh | 左手/前臂顶点 | 2.8 mm | FAIL（量级小） |

即：手臂一摆，大腿表面的肉被拽着走最多 11 cm——这正是 Quinn 看到的"粘连"：不是两块网格贴近，而是大腿网格被手臂骨直接拖动变形。

### 证据 2 — 权重普查
- 左大腿主导顶点 7,845 个中 **4,223 个带手臂骨权重**，交叉权重总和最高 0.72；右大腿 7,870 个中 **4,310 个**，最高 0.75。
- 反方向（手/前臂顶点带腿骨权重）：左侧 710/5,925（最高 0.06），右侧 786/15,498（最高 0.27）。
- 跨侧（左↔右）交叉权重 = 0，干净。
- 每点影响骨 ≤ 4、权重和归一，合格；微权重（<0.01）共 9,002 个待清。
- 成因推断：当年距离衰减重涂时，手臂骨（尤其 Upperarm/Forearm）的衰减范围覆盖到了大腿上段顶点，权重虽分散在多根臂骨上、单根不大，但总和可观，杠杆扫描下现形。三验当时查了单骨影响的存在性，没有查「异区探针位移量」这条定量线——验收漏项的根源在此，S2 起按指导 ①.4 三张表执行。

### 证据 3 — 间距曲线（B 类贴碰，次要）
- 左侧：全周期最小 1.12 cm（第 23 帧），31 帧中 7 帧 < 2 cm 合格线——左手摆过时确实离大腿偏近，属姿势层问题，随 P1 的 run 4.2 m/s 重制一并修（手臂外展 3–5 cm 口径）。
- 右侧：全周期恒约 0.2 cm——此数被右手所持长剑的顶点污染（右臂探针顶点 15,498 vs 左臂 5,925，差出的约 9,500 点为剑身，其主导骨为右手骨、位置贴大腿），不作为手-腿贴碰证据；剑与腿的间距另行目视确认。

### 证据 4 — run 自然速度（手感线）
Hip 骨水平位移实测 2.827 m / 周期 1.25 s = **2.26 m/s**，与代码移速 4.2 m/s 的滑步率 ≈ 46%，与 Fable 推算（45%）一致。A 路线重制目标：自然速度 4.2 ± 0.2 m/s。

## 修法（按指导 ①.3 A 类）
1. 热修（本轮）：对已入库 GLB 做外科式权重清理——手臂主导顶点清零全部腿骨权重、大腿主导顶点清零全部手臂骨权重、清微权重、限 4 影响、重新归一；复跑本诊断全套，杠杆异区位移 < 1 mm 才算过；再过 Godot `--verify` + `--demo --god` 回归后入库。原文件保留在 git 历史（8934bd7）可回滚。
2. 根治（P1）：新主角 feisun_s2 的权重流程直接带上①.4 三张表验收；run 按 A 路线重制，顺带解决左侧 1.12 cm 的 B 类贴碰。
