# 方向：可走的大地图「守灯原」

把现在的封面和营地卡片换成一张**可以走的大地图**：绯隼直接在地图上走动，走到关卡入口就能进关；营地里的 NPC、试炼、训练场都是地图上的地点。全部原创：地名、人物、故事都是这个项目自己的，不照搬任何现有作品。

素材需求和给 Codex 的提示词见 `docs/ART_V7.md`。素材回来之前，地图先用程序画的占位美术把玩法做好、调好手感，回来以后再替换（和 ART_V6 的做法一样）。

---

## 一、为什么做、要达到什么

| 现在 | 换成大地图以后 |
|---|---|
| 进游戏是一张标题图，按键后是 HTML 卡片列表 | 进游戏就站在地图上，标题浮在地图上方，按键后标题淡出、直接开始走 |
| 关卡是一张张卡片，点「出征」 | 关卡是地图上的入口（墓园、塌陷的骨阶、刑场……），走过去、按攻击键进入 |
| 「长夜里的灯一盏盏暗下去」只写在开场卡里 | 地图上能**看见**：五座烽灯只有通关的那几座亮着，越往后地图越亮 |
| 训练场、残光试炼是两张卡 | 营地旁边的练剑场、营地另一边的试炼碑 |
| 角色 / 技能 / 委托是三个标签页 | 保留这些面板（菜单还是 HTML 好用），从地图上随时打开（按键或屏幕右上角按钮），以后也可以找对应的 NPC 打开 |

**不变的**：关卡本身、战斗、成长、装备、存档、难度、试炼规则都不动。地图只是「入口」这一层。

## 二、地图「守灯原」

### 空间和视角

- 逻辑尺寸 **2400 × 1500**（屏幕是 960 × 540，横向约 2.5 屏、纵向约 2.8 屏），镜头跟着人走，到边缘停住
- **俯视 3/4 视角**（镜头朝下约 45°）：地面、地标、散件都按这个角度画；人物用现有的侧面逐帧精灵（这种「俯视地图 + 侧面人物」的搭配看起来是自然的）
- 地图上的人物比战斗里小：站立约 **58 像素**（战斗里约 96），让地图显得大
- 人物可以八方向自由走动（键盘 WASD / 方向键，手机左下摇杆），按纵深（y）排序遮挡：走到地标后面会被挡住
- 碰撞：地标、树、石头的「底座」是椭圆，不能穿过；地图四周是枯林和断崖，走不出去

### 布局（逻辑坐标，左上角是 0,0）

```
                       ⑤ 残光深渊（1200, 230）
                    —— 断桥伸进深渊，光从下面往上冒

  ② 骸骨回廊（1000, 600）                         ④ 深渊祭坛（1900, 470）

          ① 墓穴入口（640, 860）          ③ 屠夫刑场（1750, 850）

     试炼碑（780, 1190）   ★ 守灯驿（1200, 1170）   练剑场（1580, 1230）
                         （起点，镜头从这里开始）
```

- 一条旧石路把它们连起来：守灯驿 → ① → ② → ③ → ④ → ⑤，路边有路牌和熄灭的路灯；没通到的路段长满荒草
- 每个关卡入口旁边立着一座**烽灯**（高高的铁灯架）：通关这一关（普通难度）以后点亮，照亮周围一片
- 守灯驿中央是**长明灯塔**：整个长夜里唯一还亮着的灯，但很暗；随着烽灯一座座点亮，它也越来越亮；打完结局，它恢复全亮

### 地点和交互

| 地点 | 走近时提示 | 按攻击键（手机：攻） | 锁住时 |
|---|---|---|---|
| ①～⑤ 关卡入口 | 「墓穴入口 · 推荐 Lv.1」 | 弹出关卡面板：说明、首领、最好评价、难度按钮（普通 / 噩梦 / 地狱），点「出征」进关 | 入口被锁链封住、蒙着雾；提示「通关『上一关』解锁」 |
| 练剑场 | 「练剑场 · 挑战 3 / 8」 | 进入训练场 | 不锁 |
| 试炼碑 | 「残光试炼 · 纪录第 N 层」 | 弹出试炼说明，点「进入」 | 通关①之前碑是暗的，提示「通关『墓穴入口』解锁」 |
| 守灯驿 | — | 第 3 轮起：和 NPC 对话 | — |

关卡面板就是现在那张关卡卡片（内容不变：说明、房间数、敌人、首领、首通奖励、评价、难度），只是从列表里单独拿出来、在地图上弹出来。

### 进关和回来

- 进关：面板里点「出征」→ 画面向入口收拢变黑（约 0.4 秒）→ 进关（照常播开场卡）
- 回来：通关 / 阵亡 / 撤退之后回到地图，**站在刚才那个入口前面**；试炼、训练场同理
- 第一次通关某关：回到地图后播一小段「点亮烽灯」（镜头停在烽灯上，火苗燃起，周围亮起来，约 2 秒，可以跳过）—— 第 3 轮做

### 菜单

- 屏幕右上角：角色、技能、委托、剧情、设置、音乐（和现在营地顶部一样）
- 键盘：**Esc** 打开菜单（和战斗里的暂停是同一个键），**B** 直接打开角色面板（背包）
- 面板打开时人物不动；关掉面板回到地图原地

### 封面

- 打开游戏：镜头从深渊方向慢慢移到守灯驿，标题「残光之刃」浮在地图上方
- 按任意键（手机：轻点）：标题淡出，镜头落到绯隼身上，可以走了
- 第一次进游戏：先播现有的「前提」卡（长夜、残光、守灯人），然后才是地图

## 三、剧情（第 3 轮做，这里先定方向）

全部是这个项目自己的故事，接着现有的设定：长夜、残光、守灯人、残光深渊、残影（「走不出去的你」）。

### 守灯驿的三个人

| 人物 | 是谁 | 在地图上的作用 |
|---|---|---|
| **烛婆** | 守灯驿最老的守灯人，看着长明灯塔。年轻时送走过很多下到深渊的守灯人，一个都没回来 | 委托、回看剧情；随着进度讲守灯人的旧事，慢慢说出「没回来的守灯人会在深渊里留下影子」—— 为残影铺垫 |
| **墨衡** | 守灯驿的铁匠。曾经也是守灯人，在刑场丢了右手，现在装着一只铁手打铁 | 装备（打开角色面板）；每次聊天按下一关给一句实用提示（「铁颚的钩子甩出来之前会在头顶转圈」） |
| **阿砾** | 在废墟里捡东西的小孩，背着一大包自己画的地道图，罐子里装着一点捡来的残光 | 指路（下一关在哪）、试炼碑的传闻；他最想看的是「真正亮着的灯」—— 结局时他看到长明灯塔全亮 |

### 地图上的剧情节点

1. **第一次来到地图**：前提卡 → 烛婆迎上来说两句（长明灯塔、五座烽灯、墓穴在西边）
2. **每关第一次通关**：点亮这一关的烽灯；回驿站时三个人的台词更新（每人每阶段 1～3 句）
3. **通关①**：试炼碑「醒来」（碑上的刻纹亮起），阿砾跑来说碑在发光
4. **通关③**：墨衡讲他在刑场丢掉手的那天（和铁颚有关）
5. **通关④**：烛婆说出影子的事 —— 下到深渊的守灯人，如果走不出来，会留下和自己一模一样的影子
6. **通关⑤（结局）**：现有的结局卡之后，回到地图：长明灯塔全亮、五座烽灯全亮，地图明显变亮；三个人各说一句；之后照常可以玩（高难度、试炼）
7. **路牌和墓碑**：地图上 6～8 处可以读的短句（旧守灯人留下的刻字），补充世界观，不强制

原则：短、可跳过、不挡路；台词用气泡和对话框（头像 + 名字 + 一两行字），和现有的首领战前台词同一套界面。

## 五、技术要点

- 新模块 `src/world.js`：地图数据（地点、道路、散件、碰撞）、地图场景（移动、碰撞、镜头、提示、交互）、绘制（素材没到之前程序画）
- 地图场景复用现有的渲染管线：光照（烽灯、长明灯塔、人物身上的光）、雾、WebGL 后处理、调色
- 地图上的人物用现有的绯隼逐帧精灵（`idle`、`walk`），不需要新动作
- 营地 HTML 面板保留，去掉「出征」标签页（关卡在地图上），加「委托」标签页
- 存档：记住最后一次站在哪个入口前（回地图时用）；烽灯是否点亮直接由「是否通关」决定，不另存
- 手机：摇杆走路，攻击键交互，右上角菜单按钮；地图素材和战斗素材一样分桌面 / 手机两套，地图上不载入任何战斗的敌人和首领图集
