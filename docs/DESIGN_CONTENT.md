# 内容设计 A：新敌人、首领专属招式与剧情框架

这份文档是「方向 A」的设计依据。美术需求和给 Codex 的提示词在 `docs/ART_V6.md`。
所有名字、剧情、造型都是原创，不照搬任何现有作品。

---

## 一、要解决的问题

| 现状 | 问题 |
|---|---|
| 3 种杂兵 + 4 个精英词缀，铺满 5 关、约 27 个房间、3 个难度和残光试炼 | 第 3 关以后就没有新东西了；难度只加数值和词缀 |
| 5 个首领共用一个 10 招的招式池（三连斩、跳劈、震地波、冲锋、齐射、天降、召唤、瞬斩、读条、咆哮） | 首领之间差别只在招式比例；夜鸦和铁颚还是杂兵放大 |
| 剧情只有首领转阶段时的一句话 | 玩家不知道绯隼为什么在这里；「残光」只是标题里的词 |

**原则**：
- 新敌人**用现有机制当解法**：施法者靠「破招 / 打断」反制，飞行群靠「浮空 / 空中连」反制。新内容让玩家把已经学过的东西用起来，而不是加新按键
- 每个首领的两个专属招式要**一眼认得出是谁**，并且有明确的解法（闪、跳、打断、弹刀、走位之一）
- 剧情**短、可跳过、不打断战斗**：文字卡 + 战前两句台词 + 结局，没有配音、没有过场动画

## 二、新敌人

### 2.1 灰烛司祭（支援施法者）

**定位**：躲在后排给同伴加盾、在你脚下放陷阱。它本身很脆，但不先处理它，前排就打不动。

**造型**：佝偻的长袍祭司，兜帽下是裂开的半张白瓷面具，手持顶端挂着铁笼提灯的长杖，提灯里是一小团灰白的火。灰色长袍、褪色的紫边、腰间挂一串小骨片。

| 数值 | 值 | 说明 |
|---|---|---|
| 血量 | 110（腐骨兵 140） | 两三下连招就倒 |
| 等级偏移 | +2 | |
| 速度 | 1.5 | 比腐骨兵慢 |
| 霸体 | 0 | 一碰就硬直 |
| 经验 / 掉落 | 22 / 30% | 优先击杀有回报 |
| 保持距离 | 220～320 | 像弓手一样后退，被贴身会推开你 |

**招式**：

1. **护咒**（核心）：举灯读条 70 帧（全身紫光 + 头顶紫色「!」），读完给 380 像素内最多 2 个同伴套上**咒盾**
   - 咒盾吸收相当于对方 30% 最大血量的伤害，持续 10 秒；带盾的敌人**不会被打出硬直**（相当于临时霸体），身上有紫色的护罩
   - **反制**：读条期间打中司祭 = **破招**（现有机制：打断 + 额外伤害 + 技能冷却回转）；重击和破招对咒盾造成双倍伤害
   - 冷却 6 秒；同一时间场上最多 1 个司祭在读护咒
2. **灰烬陷阱**：杖尾敲地 36 帧，在你当前位置画一个地面符文（用 ART_FX 的首领符文圈贴图，灰紫色），40 帧后点亮，之后 6 秒内你踩进去就爆炸（伤害 12，浮空）
   - **反制**：看到地面符文就绕开或跳过去；坠星斩、崩山击落在符文上能直接引爆它（不伤你）
   - 每个司祭最多同时 2 个陷阱
3. **推开**：被贴身（90 像素内）时 20 帧的杖击，伤害低但击退远，用来逃跑

**和词缀的搭配**：可以带「狂暴」（读条变快）、「爆裂」；不带「坚盾」「迅影」。

### 2.2 烬翼（小型飞行群）

**定位**：三五只一群，在你头顶上方盘旋，地面普攻够不着；俯冲时才降到低处。逼你跳起来用空中连招，或者看准俯冲反打。

**造型**：蝙蝠一样大小的焦黑小兽，皮肤龟裂、裂缝里透出暗红的余烬纹路，膜翼残破，细长的尾巴，两点针尖般的眼睛。

| 数值 | 值 | 说明 |
|---|---|---|
| 血量 | 34 | 一两下就死 |
| 等级偏移 | 0 | |
| 飞行速度 | 3.2 | 绕着你飘 |
| 盘旋高度 | 115～140（上下浮动） | 地面普攻（判定顶到 100～110）打不到；上挑（130）和回风斩（120）在它浮到最低点时能打到 |
| 经验 / 掉落 | 8 / 8% | |
| 出场 | 一组 3 只（噩梦 4 只、地狱 5 只） | 波次表里写 `wing` 就出一组 |

**招式**：

1. **俯冲**：悬停 28 帧（身上一闪 + 红光），然后朝你斜着俯冲到离地约 20 的高度，冲 16 帧再爬升回去
   - 伤害 7，击退小；俯冲和爬升途中（离地 100 以下）地面攻击能打到 —— **看准俯冲反打就是破招**
2. 被打中：在空中被打就失去平衡**掉到地上**挣扎 60 帧，期间能被地面攻击追打，之后重新起飞
3. 占用攻击令牌：同一时间最多 2 个敌人进攻的规则对它一样有效，不会一群同时扑下来

**反制总结**：跳起来空中连（一刀一只）、上挑捞最低点、俯冲时反打、落地后追打（掉在地上的烬翼什么攻击都能打）。崩山击判定够高；回风斩在它浮低时能扫到。

**和词缀的搭配**：可以带「狂暴」；不带「坚盾」「迅影」「爆裂」（爆裂的爆炸贴着地面，打不到空中的同伴）。

## 三、首领专属招式（每个首领 2 个）

现有的 10 个通用招式保留；每个首领再加 2 个只有它会用的招式，主要放在第二阶段，让「转阶段」真的有变化。

| 首领 | 招式 | 预警 | 招式内容 | 解法 | 出现 |
|---|---|---|---|---|---|
| **骸骨统领** | **骨牢** | 你脚下一圈 6 个骨刺红圈，留一个缺口 | 40 帧后一圈骨刺同时破土（用 FX-3 骨刺），中间再补一根 | 从缺口冲出去；或者算准时机原地跳 | 第一阶段起 |
| | **裂地追斩** | 巨剑拖地，地上一条红线指向你所在的纵深 | 三根骨刺沿直线一根接一根追着你冒出来（每根间隔 14 帧，会追你的纵深） | 纵向走位甩开；第三根后它有 40 帧收招破绽 | 第二阶段 |
| **夜鸦** | **羽刃回旋** | 张开斗篷，扇形三条紫线 | 扔出 3 片羽刃，飞出去再**拐回来**（回旋镖），去程和回程都有判定 | 去程闪过后注意回程；在它扔出时打它是破招 | 第一阶段起 |
| | **鸦影分身** | 化作一团黑羽 | 分成 3 个身影站成一排同时拉弓；只有一个是真身（脚下有细微的影子），其他两个的箭是假的（打中只闪一下） | 找到真身打中它 = 打断全部分身；或者躲开全部箭 | 第二阶段 |
| **铁颚** | **锁链钩** | 甩动锁链，地上一条红色窄线 | 把钩子沿直线甩出；被钩中会被拉到它面前，紧接一记重锤 | 横向闪开；**被拉过去时可以弹刀**（拉到身前的瞬间出刀）反打 | 第一阶段起 |
| | **刑台三震** | 双手举锤，前方出现三个依次变大的红圈 | 向前连砸三下，一下比一下远、一下比一下大，第三下向两边炸出震地波 | 后撤到第三圈外；或在第一下后贴身绕背 | 第二阶段 |
| **祭坛守护者** | **魂火炉** | 地面浮现召唤法阵（FX-3） | 在场上召出 3 座魂火炉（能被打碎的物件），每座每隔几秒朝你吐一颗魂火 | 先拆炉子再打首领；炉子会在 15 秒后自己熄灭 | 第二阶段 |
| | **审判长戟** | 长戟后拉，**两条**纵深不同的红色光带 | 一记横扫打第一条，紧接着回扫打第二条 | 站在两条光带之间的空隙；或跳过第一扫 | 第一阶段起 |
| **残影** | **镜像** | 身上闪过你最后用过的技能图标 | 复制你**最后用过的技能**还给你：裂空斩 → 剑气、回风斩 → 回旋、崩山击 → 震地、千刃 → 突进连斩 | 你用什么技能决定它下一招打什么 —— 可以故意先用好躲的技能「喂」它 | 第二阶段起 |
| | **残光处决** | 屏幕暗下来，多条红色路线连成折线 | 沿折线瞬身连斩 5 次（像你的必杀），最后一斩落在你身上 | 每一斩都能极限闪避；全部闪过它会力竭倒地 3 秒 | 最终阶段 |

数值原则：专属招式的伤害和同阶段通用招式相当（不是秒杀技），**难在读，不难在数值**；每个招式都有明确的收招破绽，奖励躲过去的玩家。

首领素材：骸骨统领、祭坛守护者用 ART_V4 已有的动作帧（骨刺、斩痕、魂火、法阵用 ART_FX 已有的特效）；残影用主角动作；**夜鸦和铁颚需要新的专属素材**（见 `docs/ART_V6.md`），素材回来之前先用现在的放大杂兵帧做出招式、调好手感。

## 四、剧情框架

### 4.1 前提（原创）

> 百年前，地表的太阳熄灭了，人们管这叫「长夜」。从那以后，世上唯一的光来自**残光**：每个死去的人都会留下最后一点光，人们把它收进灯里，照明、取暖、种出庄稼。
> 所有没被收起的残光，最后都会沉进大地深处的**残光深渊**，再慢慢浮回地面。
> 可是这几年，深渊不再归还光了。地上的灯一盏接一盏暗下去。
> **绯隼**是守灯人一脉最后的剑士。她的刀「残光之刃」能把斩开的黑暗化成光。她下到深渊，去找吞掉光的东西。

逐关揭示的真相：每一个倒在深渊里的挑战者，都留下了一道「残影」。深渊最深处，这些残影聚成了一个和绯隼一模一样的身影 —— 它吞食残光，是想变成「真正的」她，走回地面。

### 4.2 每关开场卡

从营地出征进入关卡时，在关卡名横幅之前显示卡片：房间画面压暗做背景，中间两到三行字逐行浮现，**1 秒后可以按攻击键翻页，每页 6 秒自动翻**；卡片期间第一波敌人不出来。第 1 关第一次进入时先播两页「前提」。默认只在第一次进入每一关时显示（设置可改「每次 / 关」）；之后只显示原来的横幅（营地里可以「回看剧情」）。

| 关卡 | 开场卡 |
|---|---|
| 墓穴入口 | 长夜第一百零七年，地表最后一座灯塔熄灭的那天，绯隼走进了墓穴。<br>腐骨兵还记得自己是守墓人，却忘了要守的是什么。 |
| 骸骨回廊 | 回廊两侧的骨头摆成了路标，全都指向更深的地方。<br>有什么东西在这里猎杀带着光的人。 |
| 屠夫刑场 | 这里曾处决偷光的人。刑台上的锁链还是热的。<br>可被吊起来的，不全是贼。 |
| 深渊祭坛 | 祭坛上的火是绿色的 —— 那是被锁住、回不了家的残光。<br>守着它们的东西，已经守了一百年。 |
| 残光深渊 | 光沉到这里，就再也浮不上去。<br>黑暗中站着一个人，握着和你一样的刀。 |

### 4.3 首领战前台词

首领出场时，在首领和绯隼头顶依次弹出台词气泡（每句最多 2.5 秒，按攻击键下一句）；台词期间首领站着不出手，你的按键也只用来翻台词。

| 首领 | 首领 | 绯隼 |
|---|---|---|
| 骸骨统领 | 活人……不许再往下走。 | 那就让开。 |
| 夜鸦 | 你身上的光，比我收集过的都亮。 | 它不是给你的。 |
| 铁颚 | 偷光的人，都要上刑台。 | 偷光的不是我。 |
| 祭坛守护者 | 这些火，是我守了一百年的东西。 | 被锁住的火，只是另一种牢笼。 |
| 残影 | 我等了你很久 —— 等你把光带下来。 | ……你是谁？ |
| 残影（第二句） | 我是走不出去的你。 | |

现有的转阶段台词保留。

### 4.4 结局

第一次在任意难度通关「残光深渊」后播放 3 张卡，然后是简短的制作名单（滚动文字），最后回营地。之后可以在营地「回看剧情」。

1. 残影倒下的时候没有消散。它化成一道光，落进了绯隼的刀里。
2. 刀身里响起很多人的声音 —— 那些没能走出深渊的人。他们不是敌人，只是迷了路。
3. 绯隼带着他们往上走。那天，地表的第一盏灯，重新亮了起来。

### 4.5 呈现与系统

- 存档新增 `story`（看过哪些卡）；设置里加一项「剧情卡：显示 / 只显示第一次 / 不显示」
- 营地加「回看剧情」入口：按关卡列出已解锁的开场卡、台词和结局
- 文字用现有的书法标题字体 + 正文字体；手机上字号不小于 18
- 不新增美术：开场卡背景用各关远景，结局卡用绯隼立绘

## 五、重平衡

### 5.1 新敌人在哪一关登场

| 关卡 | 新内容 | 普通房间波次（示意） |
|---|---|---|
| 墓穴入口 | 不加（教学关保持干净） | 不变 |
| 骸骨回廊 | **烬翼登场**（和夜鸦的「回廊猎手」主题呼应） | 加入 `wing` 组；精英房 `grunt*` + `wing` |
| 屠夫刑场 | **灰烛司祭登场**（给屠夫加盾，逼你先处理后排） | `brute` + `priest`、`grunt ×2` + `priest` + `archer` |
| 深渊祭坛 | 两种混合 | `priest` + `wing` + 前排；精英房 `brute*` + `priest*` |
| 残光深渊 | 全部混合，精英司祭 | 每个房间至少一种新敌人 |

### 5.2 难度

- 噩梦 / 地狱：烬翼一组多 1 / 2 只；司祭的护咒范围更大、陷阱点亮更快（随现有的 `windup` 倍率）
- 普通怪带词缀的概率规则不变；新敌人只能带上面列出的词缀

### 5.3 残光试炼

- 第 4 层起波次池加入烬翼，第 7 层起加入司祭
- 首领层轮换不变，五个首领都带上专属招式

### 5.4 验收指标（用现有的通关机器人测试）

- 普通难度五关全部能通关，通关帧数比现在增加不超过 25%
- 地狱难度五关全部能通关
- 首领战：每个专属招式在机器人测试里至少出现一次、没有卡死（`stuckMax` 不明显上升）
- 手机：同屏敌人上限不变；新角色图集按关卡载入

---

### 5.5 第五轮实测（通关机器人，模拟同一套随机打法）

| | v26（改动前） | 第五轮之后 | 变化 |
|---|---|---|---|
| 普通五关总帧数 | 52,969 | 47,939 | −9%（目标：不超过 +25%） |
| 噩梦五关 | — | 72,368，全部通关 | |
| 地狱五关总帧数 | 95,697 | 80,635，全部通关 | −16% |
| 卡死指标 `stuckMax` | 189～457 | 197～437 | 没有上升 |

机器人打法是随机的，同一版本两次跑的差距可以到 ±10%；结论是新敌人和专属招式没有让关卡变成拖沓的消耗战。
手感上的难度（读招、打断、空中连）需要真人来判断，见第六轮之后的体验清单。
