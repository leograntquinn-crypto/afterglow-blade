# 核心循环研究：战斗 — 成长 — 挑战 — 再战斗

v14 的破招、冷却回转、首领读条、武器流派是**单次交锋**层面的对抗机制。这份文档往下挖一层：玩家为什么要打下一场、打得好和打得差到底差在哪、成长有没有改变打法。

## 一、现在的核心循环（按时间尺度拆开）

| 尺度 | 循环 | 玩家的决策 | 风险 | 回报 |
|---|---|---|---|---|
| **秒**（一次交锋） | 看预警 → 闪避 / 弹刀 / 破招 / 继续连 → 取消 → 技能 | 很密：每 1～2 秒一次 | 掉血、被打断连段 | 伤害、风格分、残光槽、冷却回转 |
| **分钟**（一次出征） | 房间 → 波次 → 房间 → 首领 | 很少：只有「去不去支线房间」 | 血量在房间之间不回满 | 经验、金币、装备 |
| **小时**（养成） | 升级 → 加点 → 换装备 → 更高关卡 / 难度 | 几乎没有：装备只比「数字大不大」 | 没有 | 数值变大 |

### 结论：秒级循环已经很深，但它和上面两层几乎是断开的

1. **打得好不会多拿东西。** 风格评级（D → SSS）只影响结算评价和必杀充能。无伤打出 SSS 和挨了 20 刀磨过去，掉的装备、经验、金币**完全一样**。所以秒级的冒险（抢攻、破招、空中连）在分钟级和小时级**没有回报**，玩家理性的选择是「稳着磨」。
2. **成长不改变打法。** 装备词条全是纯数值（力量、暴击、攻击 %……），技能升级是 +12% 伤害。比较装备只看「战力」高低。v14 的武器流派是第一个改变打法的成长，但只有 3 种、只在武器上。玩家没有理由去「打出某种打法」，因为没有装备奖励某种打法。
3. **失败不告诉你哪里错了。** 死亡画面只写「力竭 · 清理了 N 个房间」。玩家不知道是被谁打死的、是不是总在同一种攻击上吃亏、该用什么机制应对。技能上限（极限闪避、破招、弹刀）存在，但失败时没有把玩家引向它。通关画面的评价也只给分数，不说怎么提高。
4. 敌人 AI 和关卡节奏（攻击令牌、最多 2 人同时进攻、远近搭配）已经在逼玩家做选择，难度阶梯（普通 / 噩梦 / 地狱）也有，**这两层暂时不是最大的缺口**。

## 二、内核改动方案（按对核心循环的提升排序）

### 1. 战意：风格评级决定战利品　→ 本轮实现
- **改变了什么决策**：每一次交锋都多了一个筹码。击杀时的风格评级越高，这个敌人掉的经验、金币越多，掉装备的概率和品质越高（SSS 时翻倍）。挨一下打风格掉两级，战利品加成跟着掉。玩家每一秒都在权衡：继续抢攻保持高评级多拿东西，还是退一步保命。
- **为什么是内核**：它把秒级循环的「打得好」直接接到小时级的成长上。以前风格只是一个好看的字母，现在它是**收益**。不新增任何操作，手机上一样。
- **为什么不会让人沮丧**：只有奖励没有惩罚，打得一般也拿基础收益。
- **范围**：小。击杀奖励处乘一个系数，风格字母下面显示当前加成。

### 2. 刻印：让装备奖励打法，而不是奖励数字　→ 本轮实现
- **改变了什么决策**：稀有和传说装备会带一条「刻印」，在你做到某件事时生效，比如「破招后 4 秒暴击率 +30%」「对空中敌人伤害 +25%」「满血时伤害 +20%」。换装备的问题从「哪个数字大」变成「我想怎么打」：带空中刻印就多打浮空连，带满血刻印就要打无伤，带背水刻印就敢卖血。
- **为什么是内核**：成长终于改变打法；刷装备有了方向（追求某条刻印），这是长期目标。每条刻印都挂在**已有的机制**上（破招、极限闪避、弹刀、空中连、追打、撞墙、连击），所以它同时在教玩家使用这些机制，提高技能上限的可见度。
- **防止臃肿**：只有 8 条；每件装备最多 1 条；同名刻印不叠加；4 个装备栏最多同时 4 条，构筑一眼看得懂。不新增按键、不新增界面层级（装备详情里多一行，角色面板列出已激活的刻印）。
- **范围**：中。装备生成、属性汇总、伤害计算和几个机制触发点各加几行。

### 3. 复盘：失败告诉你输在哪、下一步练什么　→ 本轮实现
- **改变了什么决策**：死亡画面列出致命一击、受伤最多的三种攻击，以及「你有多少伤害是在自己出招时吃到的」（贪刀），再给一条针对性建议（「铁甲屠夫·重砸打中你 4 次：看到地上的红圈就闪避穿过去，或用重击破招」）。通关画面在最弱的评价项下面给一条提升建议。
- **为什么是内核**：动作游戏的复玩靠「我知道我下次能做得更好」。现在失败是模糊的，复盘把失败变成下一局的具体目标，并把玩家引向破招、极限闪避、弹刀这些上限机制。
- **范围**：小到中。受伤时记一条日志（来源、招式、是不是在出招中），死亡和通关画面各加一块。

## 三、否掉的深层想法

| 想法 | 为什么不做 |
|---|---|
| **死亡丢失本次收获**（加重失败惩罚，提高紧张感） | 手机玩家常被打断、单局时间零碎，丢东西会直接劝退；而且「战意」已经用奖励制造了风险回报，没必要再加惩罚 |
| **体力条**（闪避、冲刺消耗体力） | 会和极限闪避、冷却回转冲突（闪避本来就是高手的进攻手段），节奏变慢；多一条资源条，手机上更难盯 |
| **自定义连招 / 连段编辑器** | 需要复杂的编辑界面，手机上很难操作；现有的取消规则已经让连段自由组合 |
| **局内随机祝福**（每局选强化，肉鸽式） | 和「刻印」功能重叠，两套构筑系统会让人看不懂；先把装备构筑做扎实 |
| **暗中动态调难度**（打得好就偷偷变难） | 破坏公平感，也让难度阶梯和评价失去意义 |
| **会学习玩家习惯的敌人 AI** | 玩家看不到规则，只会觉得「不公平」；现在的「预警 + 攻击令牌」规则清楚，是更好的基础 |
| **更多主动技能 / 技能分支** | 用户要求的是内核而不是新技能；技能数量不是现在的瓶颈 |
| **敌人围攻时惩罚贪刀**（打一个敌人太久，其他敌人立刻进攻） | 方向对，但现在两人同时进攻的上限 + 预警已经在做这件事；改 AI 节奏要大量实机手感调试，先用「复盘」量化贪刀，下一轮再根据数据决定 |

## 四、具体规则

### 战意（`src/main.js`：`spoilsMul`）
| 风格 | D | C | B | A | S | SS | SSS |
|---|---|---|---|---|---|---|---|
| 战利品加成 | 0 | +10% | +20% | +35% | +50% | +70% | +100% |

作用于：击杀经验、掉落金币、掉装备概率（普通怪）、装备品质（运气）。首领和通关奖励按击杀 / 通关瞬间的评级算。

### 刻印（`src/items.js`：`MARKS`）
| 刻印 | 效果 | 鼓励的打法 |
|---|---|---|
| 断势 | 破招后 4 秒内暴击率 +30% | 预判抢攻 |
| 凌空 | 对空中的敌人伤害 +25% | 浮空连 |
| 残心 | 极限闪避后 3 秒内技能伤害 +40% | 闪避反击 |
| 无瑕 | 满血时伤害 +20% | 无伤 |
| 背水 | 生命低于 35% 时伤害 +35% | 卖血 |
| 追魂 | 追打倒地不打折，每次追打回复 2% 生命 | 扫腿 / 坠星追打 |
| 震壁 | 撞墙反弹后 3 秒内，该敌人受到伤害 +40% | 推墙 |
| 连锋 | 连击每 10 下伤害 +5%（最多 +25%） | 长连段 |

- 稀有装备 40% 带一条，传说装备必带一条；每件最多一条
- 同名刻印不叠加

### 复盘（`src/main.js`：`recordHurt`，`src/hud.js`：死亡 / 通关画面）
- 每次受伤记录：来源（敌人和招式名）、伤害、是否在自己出招时被打中
- 死亡画面：致命一击、受伤最多的三种攻击（次数 + 总伤害）、贪刀比例、一条针对性建议
- 通关画面：最弱的评价项下面给一条提升建议

## 五、需要玩家亲自验证的核心手感
1. 战意加成是否真的让你更愿意冒险抢攻（而不是更怕挨打）
2. 刻印是否让你愿意为了某种打法换装备，哪一条最好用、哪一条没人用
3. 死亡复盘的建议是否说中了你真正的问题
