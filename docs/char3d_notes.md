# 角色 3D 管线备忘（2026-11-10 Muse 实测）

## heroine3d.glb（蒙眼剑士，TRELLIS 图生 3D）结构

- 节点：Node3D ×2 + MeshInstance3D ×1 —— **单个静态网格，没有骨骼（Skeleton3D）、没有动画（AnimationPlayer）**。
  这是图生 3D 的常态：模型本身不能动，上动画必须先绑骨。
- AABB：[P: (-0.218, -0.501, -0.139), S: (0.434, 1.000, 0.277)] —— 高约 1.0 单位、原点在身体中心。
  缩放到 1.7m：scale ≈ 1.70，脚底对齐需把网格向上抬 0.5×scale。
