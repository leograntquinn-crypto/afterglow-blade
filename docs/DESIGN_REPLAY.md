# 可玩性：让玩家多玩几局

第 15 版已经有：战意（风格 → 战利品）、刻印、复盘、破招、冷却回转、首领读条、武器流派、5 关 × 3 难度、训练场、精英词缀。这份文档审查**系统层**：玩家为什么开下一局。

## 一、审查

| 方面 | 现状 | 缺口 |
|---|---|---|
| 成长与构筑的分支 | 属性点（可免费重置）、技能升级（每级 +12%）、装备（随机词条 + 随机刻印）、武器流派 | **构筑只能等运气**。刻印完全随机，玩家想走「浮空流」「破招流」也没办法朝目标努力；有方向的选择只有换武器类型 |
| 重复游玩的目标 | 每关每难度的首通 ×3、最佳评价 | 打完地狱就没有目标了；**每次打开游戏没有「今天打什么」**。金币只能用来强化，攒多了没用 |
| 挑战与奖励 | 噩梦 / 地狱、可选的精英房 | 没有「越打越难、看自己能撑多久」的挑战，也没有可以刷新的个人纪录 |
| 失败与成长的反馈 | 第 15 版的复盘 | 够用 |
| 手机上的节奏 | 一次出征 3～6 分钟，可以撤退 | **没有能在两三分钟内打完的短局**；训练场没有奖励 |

## 二、方案（按收益排序）

### 第一步：委托 + 铭刻　→ 本轮实现

**委托**：营地「出征」页顶上有 3 张委托，比如「破招 12 次」「无伤清空 3 个房间」「通关 骸骨回廊·噩梦」「装备太刀通关任意关卡」。进度在每次出征中累计（训练场不算），完成后回营地领取**刻印石**和金币。领过的那一格**第二天**补上新委托；没完成的不会过期；每天可以免费换掉一张。

- **改变的决策**：每次打开游戏都有「这局去哪、用什么打法」的具体目标；委托会把玩家推向他平时不用的机制（弹刀、空中连、撞墙）、没打过的难度和武器流派，等于用奖励带着玩家探索已有内容
- **为什么值得做**：成本低（全部挂在已有的事件上），却直接回答了「今天为什么再打一局」
- **会不会臃肿**：不加新标签页，只在出征页顶部多一行三张卡片；没有体力、没有过期惩罚、没有登录奖励

**铭刻**：稀有和传说装备可以花 1 颗刻印石，**指定**一条刻印（覆盖原来的）。

- **改变的决策**：构筑从「等运气」变成「有计划」。拿到一件好底子的装备，就可以决定它往哪条打法走；刻印石有限，所以要想清楚先给哪件、给哪条
- **为什么值得做**：让第 15 版的刻印真正成为构筑系统；委托的奖励有了明确的用处
- **会不会臃肿**：只在装备详情里多一个按钮和一个八选一的列表；不引入材料种类、配方、成功率

### 第二步：残光试炼（无尽层）→ 本轮实现

营地里的一种新挑战：一层一个房间、一两波敌人，**每层都比上一层强一点、多一点词缀**，每 5 层是首领层。死亡或撤退时结算：最高层数是个人纪录，每到新的 5 层里程碑给刻印石；层与层之间可以选择「继续」或「带着奖励离开」。

- **改变的决策**：每过一层都要决定**再冒一层险还是收手**（越往上奖励越多，死了这一局的层数奖励减半），这是一个清晰的风险回报选择；构筑（刻印、流派）在高层被真正检验
- **为什么值得做**：一层 30～60 秒，**手机上随时打几层**；纪录给了长期目标；完全复用现有的房间、敌人、词缀、首领，不需要新素材
- **会不会臃肿**：出征页多一张卡片，房间之间多一个「继续 / 离开」选择；不新增数值体系（层数就是关卡等级）

## 三、否掉的想法

| 想法 | 为什么不做 |
|---|---|
| 体力 / 每日次数限制 | 限制玩的次数，和「让人多玩几局」相反 |
| 登录奖励、连续签到 | 不是玩法，只是把人拉回来；断签惩罚让人有压力 |
| 抽卡 / 宝箱付费感的随机奖励 | 和动作游戏的成就感冲突，也不是原创方向 |
| 成就墙 | 收集图标改变不了任何决策；委托已经覆盖「引导玩家尝试」的作用 |
| 技能变式（每个技能二选一的分支） | 方向不错，但每个变式都要新的招式数据和特效，属于战斗内容而不是系统；放到下一批 |
| 材料打造 / 多种货币 | 刻印石一种就够，多种材料会让营地界面变成仓库管理 |
| 局内随机祝福（肉鸽） | 和刻印构筑重叠，两套系统并存会让人看不懂 |
| 排行榜（和别人比） | 需要共享数据和防作弊；先做个人纪录，以后再考虑 |

## 四、需要玩家亲自验证
1. 委托的目标是否「刚好够一两局完成」，太难或太简单
2. 铭刻之后，有没有让你开始围绕一条刻印去搭配装备
3. 残光试炼「继续还是离开」的选择是否真的让人犹豫
4. 手机上打几层试炼的节奏是否舒服
