# 工单 C1：3D 战斗竖切（竞技场内三连斩 vs 3D 敌人）

背景：全 3D 方向已定，arena3d 竞技场验证已过（scenes/arena3d.tscn + scripts/arena3d.gd 在仓里，先读它）。
本工单在竞技场环境里做出**可玩的 3D 战斗**：玩家三连斩打 3 个敌人，打击参数全部沿用已验证的
网页版/Godot 2D 竖切数值（见 scripts/player.gd、scripts/grunt.gd、scripts/stage1.gd，先读）。

## 交付物（新建文件；arena3d 与 stage1 的文件不许改坏，复用优先于复制）

1. `scenes/combat3d.tscn` + `scripts/combat3d.gd`（战斗场景与总控：顿帧、震屏、波次、胜负字）。
2. `scripts/player3d.gd`（玩家：移动/跳跃/三连斩/受击）。
3. `scripts/enemy3d.gd`（敌人 AI 与受击）。
4. 不要执行 git 操作。不要改 project.godot 主场景。

## 规格

- **环境**：复用 arena3d 的竞技场（地面/柱子/拱门/火把/雾/碰撞）。若 arena3d.gd 的构建函数不可复用，
  可把环境构建抽成 `scripts/arena_env.gd` 静态函数供两边调用（arena3d 行为必须保持不变、仍可运行）。
- **玩家**：蒙眼剑士模型（res://art/models/heroine3d.glb，1.7m 归一、脚底对齐，同 arena3d 的做法）。
  - WASD 相对相机全方位移动 4.2 m/s、平滑转身；Space 跳跃；鼠标拖拽环绕相机（同 arena3d）。
  - **J 攻击三连斩**（帧数据 @60fps，与 2D 版一致）：整套 22 帧、第 10 帧起可取消衔接下一段、
    接触帧命中（每段在出招后约第 6 帧做一次前方扇形判定：距离 ≤2.1m、夹角 ≤70°），每段伤害 12，
    出招时小幅前踏；第三段为终结技：伤害 16、顿帧更长。
  - 斩击表现：出招时在身前生成一道弧形刃光（扇形网格 + 加色半透材质，尖端亮、内侧渐隐，
    存续约 0.12s 后淡出）——竖切占位表现即可，但在代码注释里标明「正式版换 CG 特效素材」。
  - HP 100；受击：闪红（材质 emission 或 overlay）、硬直 12 帧、被击退 1.2m。
- **敌人**：3 个「腐骨兵」代理体（用基础几何拼：深铁色躯干/头盔/肩甲 + 红色发光眼点 + 一把盒体拼的刀，
  约 1.8m；注释标明是代理体、正式版换图生 3D 模型）。
  - HP 60；行为：待机→发现玩家（≤14m）走向玩家（1.6 m/s）→进入 2.0m 后蓄力**21 帧**（刀举起发亮提示）→
    挥砍（前方 2.2m 扇形，玩家中招扣 8）→恢复到第 49 帧→冷却 rng 46–84 帧（种子固定便于验收）后重复。
  - **防连晕（与 2D 版一字不差地移植）**：连续受击链窗 75 帧；硬直倍率 max(0.4, 1−0.2×(链数−1))、下限 4 帧；
    第 4 次连续非重击触发挣脱（80 帧霸体、不吃硬直）；重击（第三段）永远打断。
  - 受击：闪白 4 帧（emission）、小击退；头顶血条（朝向相机的红条，用 QuadMesh billboard 或 Sprite3D，
    受损才显示）；HP 归零：倒地（旋转倒下）+ 1 秒后淡出移除。
- **打击感**：命中顿帧（轻击冻结 6 帧、终结 8 帧，冻结双方逻辑与动作）、命中震屏（trauma 0.25 起、上限 0.6、衰减），
  实现方式参考 scripts/stage1.gd 的 frozen/trauma 结构，3D 相机震动用偏移噪声。
- **HUD**：左上玩家血条（Control 矩形条即可）；全灭时中央显示「肃清」两秒。
- **演示与验收（必须实现）**：
  - `--demo`：玩家自动索敌（走向最近的活敌、进入 1.9m 自动出招），相机缓慢环绕。
  - `--capture`：t≈1.5/3.5/5.5/8.0 截帧存 `shotc_1.png`…`shotc_4.png` 后退出（写法同 arena3d）。
  - `--verify`：无头自检模式——把一名敌人放在玩家正前方 1.6m，玩家自动连打三段，
    打印每段命中与敌人 HP 变化、四连击触发挣脱、敌人死亡，末行打印 `VERIFY PASS` 或 `VERIFY FAIL` 及原因。

## 验收标准

1. 无头运行 combat3d 无 SCRIPT ERROR；`--verify` 打印 VERIFY PASS（三段命中、伤害 12/12/16、挣脱触发、敌人可被打死）。
2. arena3d 场景仍可无头运行无错误（复用没有破坏它）。
3. Xvfb+opengl3 下 `--demo --capture` 四帧齐全，画面能看到玩家、敌人、血条（Muse 人工看图核验）。
4. 参数常量集中、中文注释；代理素材与占位特效在注释中明确标「正式版替换」。
