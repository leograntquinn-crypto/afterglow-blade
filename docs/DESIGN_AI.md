# 敌人智能：和主角博弈

目标：敌人不再「见人就冲上来打」，而是会看主角在干什么、会分工、会抓破绽 —— 但始终公平、可读、有解。
全部是通用的动作游戏设计思路，敌人和故事沿用本作原创的设定。

---

## 一、现状：为什么敌人显得笨

`src/enemy.js` 的 `think()` 只有一条判断链：

1. 算一个站位点（近战：主角前方攻击距离处，排队的多退一段；弓手：固定站在 300 外，被贴身就后跳）
2. 走过去
3. 冷却到了、拿到攻击令牌、和主角同一纵深、距离够 → 预警、出招；突刺是每帧 3% 的随机

问题：

- **不看主角在干什么**：出招、收招、闪避、在空中，对敌人来说都一样，只看距离
- **没有位置意识**：所有近战都从同一侧、同一条线上排队过来，不包抄、不用纵深
- **攻击令牌只限人数**：同时最多 2 个人进攻，但没有分工（谁压上、谁绕位、谁掩护）
- 结果：「走近 → 红光 → 挥刀」的固定套路，玩家总能先手

灰烛司祭（加盾、陷阱）和烬翼（悬停俯冲）已经有角色行为，但同样不读主角的状态。

## 二、六条原则（每一轮都不能破）

1. **不作弊**：敌人只看玩家屏幕上也看得到的信息 —— 主角的位置、朝向、正在出的招、收招还剩几帧、是否在闪避 / 空中。**不读按键输入缓冲**，不在玩家按键的同一帧反应
2. **有反应时间**：敌人看到的是 N 帧之前的主角（普通 18 帧、噩梦 14 帧、地狱 10 帧）
3. **每个新行为都有可读的提示和对应的解法**：原有的红光预警保留；新增的提示有后撤步、侧移、「破绽」字样、背后来袭的方向提示
4. **保留攻击令牌**：同时真正威胁玩家的人数不变（普通 2、噩梦 / 地狱 3），变的是其他人在干什么
5. **连段保护**：主角正在打连段时，其他敌人不插入新的进攻（有上限，防止无限拖住）
6. **数据化**：每种敌人的「性格」写成数据表（`src/ai_data.js`），调手感改表

## 三、实现：三层

### 1. 感知层（`src/ai.js` 的 Perception）

每帧记录一份主角的「看得见的信息」：位置、朝向、高度、状态、当前招式、招式进行到第几帧、有效帧什么时候结束、这一招打中没有、是否在收招、是否打空、是否在闪避、是否在蓄力、连段数。
最近 30 帧存成一个环。每个敌人按自己的反应时间取较早的一帧 —— 敌人永远在对「过去的主角」做反应。

「打空」的定义：地面普攻（不是技能、不是空中招）的有效帧已经结束，而这一招一个敌人都没打中。

### 2. 意图打分（每种敌人一个「大脑」）

把单条判断链换成「候选动作打分」：

- 候选：**压上**（走到攻击距离出招）、**踩线**（守在攻击距离边缘进进退退）、**后撤**、**侧移**（换纵深）、**包抄**（绕到主角另一侧）、**惩罚**（抓破绽）
- 分数 = 性格权重 × 局势因素（距离、主角状态、有没有令牌、导演给的角色）+ 少量随机
- 每 8 帧左右重新打分，选中后至少坚持一小段（不抽搐）
- 执行层（预警、出招、受击）不动 —— 只换「下一步做什么」，风险可控

### 3. 战场导演（全局）

每半秒给场上（用新大脑的）敌人分配角色：

- **前锋**：离主角最近的那个，负责压上
- **包抄**：第二个，目标是主角的另一侧（墙边太窄就不包抄）
- **外圈**：其余的在外圈踩线、错开纵深等待

另外两件事：

- **总有人在压**：太久没人进攻（普通约 2.5 秒），前锋的「压上」分数加倍
- **连段保护**：主角连段 3 下以上、最近 0.7 秒内还打中过人 → 除了正在挨打的那个，其他敌人不开始新的进攻；最长保护 3 秒

### 调试可视化

开发用的叠加层（按 F3，或地址加 `?ai=1`）：每个敌人头顶显示角色、当前意图、反应时间；画面左上角显示导演状态（谁是前锋、连段保护是否生效、多久没人进攻），第 3 轮起还显示读习惯的四项程度（0～1）、佯攻倍率、距上次佯攻多久、记下的闪避落点。

## 四、各类敌人的博弈行为

| 敌人 | 新行为 | 玩家的解法 | 轮次 |
|---|---|---|---|
| **腐骨兵** | **踩线**：守在你刀够不到的边缘进进退退；你逼近它就后撤一步。**惩罚打空**：你挥空了，它头上冒「破绽」、短预警后突刺过来。**包抄夹击**：两个以上时一个绕到你另一侧，前后夹击；背后来的攻击在你身边有方向提示 | 用中距离技能（裂空斩）、冲刺斩抓它后退；别对着空气挥刀，挥空了就冲刺取消、闪避或弹刀；被夹击时拉开纵深、用回风斩 | 1 |
| **铁甲屠夫** | **逼墙角**：你离墙 300 以内时从开阔一侧逼过去（在你和墙之间时先让开纵深再绕）。**甩开贪刀**：约 2 秒内被你打中 6 / 5 / 4 下（普通 / 噩梦 / 地狱）且你还贴着它 → 头上「甩开」、身边一圈红圈，短预警后把你震开。**正面格挡**：看到你面向它蓄力、或重击 / 技能正朝它打过来 → 「举斧格挡」（冷色光 + 举斧姿势），正面全挡、背后打得到、必杀不挡，不到 1 秒放下。**延迟重砸**：重砸预警过半时看到你在闪避 → 斧头多举 14～18 帧再砸，红圈位置不变 | 绕背、破防技能；打几下就退；蓄力前先绕到背后；看红圈不看节奏 | 2 ✅ |
| **影弓手** | **掩体**：冷却时躲到屠夫身后。**保持射线**：同伴挡在箭的路线上就换纵深再射，不隔着同伴放箭。**预判射击**：按看到的你的纵深移动方向把箭往前偏，预警时画出红色虚线瞄准线（就是箭的真实路线）。**墙边侧闪加踢**：后面是墙、你贴上来 → 往纵深侧闪，再一记飞踢把你踢开 | 看虚线、换方向或停一下；绕过屠夫去打它；逼到墙边时注意飞踢 | 2 ✅ |
| **灰烛司祭** | **护挨打的**：你最近 2 秒内打中过的同伴排第一个加盾（读条时头上显示「护同伴」）。**先找掩护**：想读护咒、身前（它和你之间）却没有同伴挡着 → 先走到最近的地面同伴身后、纵深错开一点，挡好了才读条；你在打连段时它照样可以护（不算进攻），但不推人、不下陷阱。**堵落点**：记下你最近 8 次闪避落在哪（相对起点、按「远离威胁」的方向），至少 3 次以后陷阱下在那个落点上，冒「堵落点」字样；没读到就和原来一样下在你脚下 | 先切司祭（绕过挡在前面的同伴）；重击破盾；闪避换方向、看地上的符再闪 | 3 ✅ |
| **烬翼** | **轮流俯冲**：同一时间只有一只在冲。**假冲 + 真冲**：一只假冲（琥珀色光、「?」、只冲下来一半就拉起、冒「虚晃」，不伤人），搭档在假冲预警进行到 55% 时开始真冲（红光「!」、冲到底、会伤人）。**起跳散开**：看到你起跳，离你 190 以内的往外散开 140，你在空中（它看得到的）时不俯冲。**落地俯冲**：看到你落地后 26 帧内，冷却剩不到 50 帧的那只马上俯冲（每次落地只来一只） | 看清哪只是红光「!」；假冲的那只别闪、留着闪避给真冲；落地后留一手闪避；对空技能 | 3 ✅ |
| **佯攻** | 腐骨兵、铁甲屠夫、烬翼。抬手和真打一样，收招前 12 帧露出破绽：**光变成琥珀色、「!」变成琥珀色的「?」、武器抖动**；腐骨兵 / 屠夫在预警 62% 处收招（冒「虚晃」，屠夫的红圈也随之淡掉、不伤人），14 帧后接一次真打（真打不会再是佯攻）。**频率上限**：每次出招的佯攻概率普通 8% / 噩梦 15% / 地狱 22%；同一个敌人两次至少隔 7 秒；全场两次至少隔 6 / 4.3 / 3.3 秒；连段保护期间不佯攻 | 看到「?」就别交闪避 / 弹刀，等真的那一下；佯攻也能照常破招 | 3 ✅ |
| **读习惯** | 只看画面上看得到的东西：敌人在你身边预警时你闪不闪、弹不弹；连段打多长（6 下以上算贪）；普攻挥空多不多；闪避往哪落。统计每 10 秒打 85 折（换打法后慢慢忘掉）。习惯明显时：常闪避 / 常弹刀 → 佯攻概率 ×最多 1.3、屠夫延迟重砸 ×最多 1.3；贪刀 → 屠夫最多早 30% 甩开；常挥空 → 腐骨兵惩罚概率 ×最多 1.3。**影响上限 30%**。第一次读到某个习惯时，画面上方提示一句（如「敌人开始提防你的闪避 —— 小心假动作」），主角头上冒「敌人在读你的打法」，每场每种只提示一次 | 换打法：别每次都闪、偶尔站住破招、连段打几下就收 | 3 ✅ |
| **首领** | 选招时加入局势权重（你远多用远程，你贪刀多用范围甩开，你常跳多用对空） | 现有读招、打断仍然有效 | 4（可选） |

## 五、分轮计划

| 轮 | 内容 |
|---|---|
| 1 ✅ | 本文档；感知层、意图打分框架、战场导演、调试可视化；**腐骨兵**的踩线、惩罚打空、包抄夹击；背后来袭提示；连段保护 |
| 2 ✅ | 铁甲屠夫（逼墙角、甩开贪刀、正面格挡、延迟重砸）、影弓手（掩体、射线、预判、墙边侧闪飞踢） |
| 3 ✅ | 佯攻（专门提示、频率上限）、读习惯（玩家模型，影响上限 30%，第一次读到时提示）、灰烛司祭和烬翼的配合 |
| 4 | 难度分档、试炼曲线、首领选招（可选）、整体回归和手感调参 |

每一轮：跑现有全套测试；为每个新行为写**确定性场景测试**（固定随机种子）；用**自动通关脚本**（会受伤、会阵亡，不是无敌的那个）对比新旧版本的通关时间、受伤次数、阵亡率；截图、记录帧率，提交合并发布。

## 六、风险和对策

| 风险 | 对策 |
|---|---|
| 整体变难，新手卡关 | 难度分档（普通反应慢、惩罚窗口窄）；用通关脚本量化，普通难度受伤次数增幅控制在约 20% 以内 |
| 被屏幕外 / 背后打，觉得不公平 | 背后来的攻击在主角身边加方向提示；包抄的敌人只在画面内出手；预警时长不缩短 |
| 佯攻让红光不可信 | 专门的提示、频率上限、普通难度少用 |
| 大家都在踩线，战斗拖沓 | 导演保证总有人在压 |
| 连招被打断，爽快感下降 | 连段保护 |
| 和现有系统冲突（令牌、破招、词缀、训练场木人） | 执行层不动；木人和首领不用新大脑；每轮全量回归 |
| 性能 | 感知是每帧一份快照，打分降频；每轮记帧率 |
| 测试变得不稳定 | AI 用自己的可设种子的随机数；新行为用确定性场景测 |
