# 核心玩法加深：借鉴「荣耀」式竞技动作网游的机制思路

只借鉴**机制思路**，不借用任何剧情、人物、名字、美术。残光之刃仍是原创世界观，主角仍是绯隼。

## 一、残光之刃现在的核心循环（研究起点）

| 层 | 已有的东西 | 缺口 |
|---|---|---|
| 进攻 | 三连斩、延迟连段、上挑 → 跳跃取消 → 空中三连、坠星斩、追打倒地、撞墙、蓄力两段、4 个技能、技能取消普攻 | 进攻只是「打得多 = 打得好」，**出手时机**没有回报 |
| 防守 | 极限闪避（子弹时间）、弹刀、受身 | 只有「等它打过来再反应」一种思路，没有「抢在它出手前打断」 |
| 资源 | 魔力、技能冷却、残光槽、风格分 | 冷却只是被动等待，和操作好坏无关 |
| 敌人 | 3 种杂兵 + 4 种精英词缀 + 5 个多阶段首领，出招都有红光预警 | 首领只有「躲 → 打」的节奏，没有需要玩家**主动去解决**的机制 |
| 构筑 | 属性点、技能树、装备（3 种武器类型 + 随机词条） | 武器类型只差在数值上，换武器**打法不变** |
| 复玩 | 每关评价、噩梦 / 地狱难度、训练场 | — |

## 二、荣耀式玩法里的机制，逐条判断

### 采用（按对核心玩法的提升排序）

**1. 破招：抢在对手出招前打断它**　→ 本轮实现
- 机制思路：竞技动作游戏里，对手出招的前摇是最大的破绽。在前摇里命中对手 = 打断它的招式，并且得到额外收益。高手对局的胜负往往取决于「谁先读出对方的出手」。
- 为什么适合：残光之刃的每个敌人出招前都有 0.4～0.9 秒的红光预警，这正好是「破招窗口」，**不用新增任何界面**。它给防守加了第三条路：
  - 等着闪避 / 弹刀（反应型，奖励是子弹时间 / 反击暴击）
  - 主动冲上去破招（预判型，奖励是打断 + 伤害 + 冷却回转）
  - 这是同一个瞬间里「手法 + 判断」的选择题，正中「考验手法和智力」的定位
- 和已有系统的连锁：坚盾正面挡普攻（破招要绕背或用重击）、铁甲屠夫有霸体（普攻破招是削霸体，重击破招才打断）、首领霸体（破招大幅削霸体）、噩梦 / 地狱预警更短（破招更难）
- 改动范围：小。命中处理加一个判定 + 反馈 + 奖励，约 60 行；训练场加一条挑战

**2. 资源和操作联动：打得好，冷却转得快**　→ 本轮实现（并入破招）
- 机制思路：冷却和魔力不该只是被动等待，高水平操作应该让技能转得更快，形成「操作 → 资源 → 更多操作」的循环。
- 怎么做：破招、极限闪避、弹刀成功时，所有技能冷却减少 1.5 秒，并回复一点魔力。
- 为什么适合：给防守和预判一个直接、看得见的进攻回报（技能栏冷却会明显跳一下），不用新增按键，手机上也一样。
- 改动范围：很小。

**3. 首领读条大招 + 打断**　→ 本轮实现
- 机制思路：首领释放大招前要「读条」，玩家必须在读条期间打出足够的打断值才能中断；打断成功给大段输出窗口，失败要承受大招。
- 为什么适合：现在的首领战是「躲 → 打」循环，玩家很被动。读条给玩家一个**主动目标**，考验爆发路线的规划：留技能、留蓄力、留必杀到读条时用，还是平时就打光？破招在读条期间同样生效，两套机制互相加强。
- 失败不是秒杀：大招是全场爆炸，可以靠跳起来或极限闪避躲开，所以失败是一次「手法补救」的机会，不是硬性惩罚。
- 改动范围：中。首领招式库加一个通用招式，5 个首领从第二阶段开始使用，首领血条下面加读条和打断进度。

**4. 武器流派：同一套动作，不同的打法**　→ 本轮实现（轻量版）
- 机制思路：竞技网游靠「职业 + 武器」区分打法，而不是只靠数值。
- 为什么适合：残光之刃已经有长剑 / 太刀 / 巨剑三种武器，但只差攻击力和暴击。给每种武器一个**改变打法的特性**，掉落装备就有了「换不换」的取舍，构筑多样性提升，而且**不需要新美术**（共用绯隼的动作）：
  - 长剑「游刃」：破招回转的冷却更多 —— 预判流
  - 太刀「疾斩」：取消窗口提前，连段更快 —— 手速流
  - 巨剑「崩山」：对霸体伤害大幅提高，普攻也能破招打断霸体敌人 —— 破甲流
- 改动范围：中小。武器类型表加特性字段，取消帧和霸体伤害各一处挂钩，装备界面显示特性。

### 暂不采用（以后有条件再做）

| 机制 | 为什么现在不做 |
|---|---|
| **多职业 / 转职**（几十个职业） | 每个职业要一整套逐帧动画，美术成本是现在的几十倍；主角身份也会被稀释。用「武器流派」先做出打法差异 |
| **一把武器多种形态切换**（战斗中切换枪 / 盾 / 剑等形态） | 是很好的高手机制，但每种形态都要整套新动作素材。等有素材后可以做成绯隼的进阶玩法 |
| **大量可选技能 + 技能栏搭配** | 每个新技能要动作、特效和平衡。现在 4 个技能 + 技能树已经有取舍；先用流派扩展构筑 |
| **自制武器 / 材料打造**（长期养成一把本命武器） | 适合做长期目标，但需要材料掉落、配方、界面一整套系统，等核心战斗加深后再做 |
| **副本记录竞速 + 全服排行** | 复玩价值高，可以用页面的共享数据库做排行。放到下一轮 |

### 不采用

| 机制 | 为什么不适合 |
|---|---|
| **团队配合、坦克 / 治疗 / 输出分工、5v5** | 单人动作游戏，没有队友；AI 队友成本高而且会抢走「自己打出来」的成就感 |
| **玩家对战竞技场、公会、交易** | 浏览器单机，没有服务器和联网同步；手机网络下实时对战延迟不可控 |
| **以手速（每分钟操作数）作为评分** | 手机触屏天然慢于键盘，会让手机玩家吃亏；评价继续用风格分（看招式多样性和时机，不看按键次数） |
| **需要鼠标精确瞄准方向的技能** | 手机上无法精确瞄准；保持「自动朝向 + 横版走位」 |
| **野外首领争夺** | 需要其他玩家才成立 |
| **浮空保护数值条** | 已经有「连续浮空越落越快」和「每次倒地只能追打一次」，再加一条数值条只会让界面更乱 |

## 三、具体规则（数值都在代码里有注释，方便调）

### 破招（`src/main.js` 的 `applyHit`）
- 判定：玩家的攻击命中处于**出招预警**中的敌人（杂兵 `windup` 状态，首领 `tele` 预警阶段）
- 杂兵：伤害 ×1.5，硬直 ×1.6，招式被打断（预警的红圈一起消失）
- 有霸体的杂兵（铁甲屠夫等）：普攻破招削霸体 ×3；重击 / 浮空招式破招直接打断
- 首领：伤害 ×1.25，削霸体 ×2.5（削空就破防，招式被打断）
- 奖励：风格分、残光槽、所有技能冷却 -1.5 秒、魔力 +8
- 坚盾照样正面挡普攻：要绕背或用重击破招

### 首领读条（`src/boss.js` 的 `channel`）
- 首领从第二阶段开始会读条释放大招，读条约 2.5 秒（越往后的阶段、越高的难度越快），脚下红圈慢慢铺满全场
- 首领血条下方显示读条进度和「打断」进度。打断值：普通命中 +1，重击 / 技能命中 +2，必杀 +4；第二阶段要 19 点，第三阶段 22 点
- 读条期间的命中都算破招（削霸体 ×2.5），所以把霸体削空也能打断
- 实测（推荐等级 7 级打铁颚）：只用普攻、每一下都卡着取消帧连，读条结束时 16 点、霸体剩 20%，打不断；普攻里插一个回风斩能到 20 点，刚好打断
- 读条结束前打满打断值 → 首领倒地破防 4 秒（伤害 +30%），风格分、残光槽、冷却回转
- 没打断 → 全场爆炸，跳到空中或极限闪避可以躲开

### 武器流派（`src/items.js` 的 `WTYPES`）
- 长剑「游刃」：破招 / 极限闪避 / 弹刀回转冷却 3 秒（其他武器 1.5 秒）
- 太刀「疾斩」：普攻和技能的取消窗口提前 3 帧
- 巨剑「崩山」：削霸体 ×1.6；普攻破招也能直接打断霸体杂兵

## 四、需要玩家亲自验证的手感

1. 破招的窗口和收益是否划算：冒险冲上去破招 vs 稳妥地等着极限闪避，两条路应该都值得走
2. 首领读条的打断值是否合适：正常连段 + 一个技能应该刚好能打断，什么都不留就打不断
3. 太刀提前 3 帧取消是否明显、是否太快
4. 巨剑破甲是否让铁甲屠夫变得太简单
