# 游戏生态：装备的一生、金币的去处、谁都能玩

前几轮补了战斗（破招、读条）、核心循环（战意、刻印、复盘）和重复游玩（委托、铭刻、残光试炼）。这一轮看**生态**：资源从哪来、到哪去，玩家投入的东西会不会白费，以及不同玩家能不能舒服地玩。

## 一、审查

### 1. 一件装备的一生：掉落 → 判断 → 穿上 → 投入 → 被替换 → 处理

| 阶段 | 现状 | 问题 |
|---|---|---|
| 投入 | 强化（金币，+7 起成功率 70%→20%）、铭刻（刻印石） | 词条完全随机，**只能等下一件**，金币没法换来「更接近理想」的装备 |
| 被替换 | 直接换，旧装备回背包 | **强化投入全部作废**。强化到 +10 要约 2.5 万金币（第 5 关等级），换一件新装备就从 +0 开始。结果玩家要么不敢强化，要么不敢换装备，两个系统互相卡住 |
| 处理 | 单件出售、一键出售普通装备 | 精良装备堆满背包要一件一件卖；没法保护想留着的装备，一键出售时心里没底 |

### 2. 金币的流向

- 收入：击杀（战意加成）、通关、委托、残光试炼（爬到 26 层约 7800）
- 支出：**只有强化**。前期强化很便宜，金币很快没用；后期又全压在强化的失败率上
- 结论：缺一个**中期就有用、能换来确定进展**的出口

### 3. 谁都能玩

- 只有「音乐开关」一个设置；减弱动态只能靠系统级的「减少动态效果」偏好
- 打击感里有大量**闪屏、冲击帧（整屏反色）、震屏、镜头推近**。这些是手感的一部分，但对光敏或容易晕的玩家是门槛；手机上也没法调按钮大小、音效音量

## 二、方案（按收益排序）

### 第一步：装备生态（传承、重铸、锁定与批量出售）　→ 本轮实现

| 功能 | 改变的决策 | 为什么值得做 |
|---|---|---|
| **传承**：新装备可以付金币继承同部位旧装备的强化等级（旧装备变回 +0） | 「要不要强化」「要不要换新装备」不再互相卡住：强化是长期投入，换装备只看底子 | 解掉两个系统互相卡住的死结；投入不会白费 |
| **重铸**：花金币把装备的一条词条重新随机（换成另一种属性），越重铸越贵 | 拿到底子好、刻印对的装备，可以花金币把差的那条词条往构筑方向赌 | 金币在中期就有确定的用处；和铭刻一起，构筑可以一步步做成 |
| **锁定 + 批量出售** | 锁住想留的，放心一键清背包 | 手机上整理背包不再一件一件点 |

- **会不会臃肿**：都在装备详情里多一两个按钮；没有新货币、新材料、新界面
- **为什么不做「分解成材料」**：多一种材料就多一套换算，和「只有金币和刻印石」的简洁经济冲突

### 第二步：设置与无障碍　→ 本轮实现

营地顶部和暂停菜单都能打开「设置」：
- **震屏强度**（关 / 弱 / 标准）
- **闪屏与冲击帧**（开 / 关）：关掉整屏反色的冲击帧和强烈闪白，打击感保留顿帧、火花和声音
- **镜头推近**（开 / 关）
- **伤害数字**（全部 / 只显示暴击 / 关）
- **音效音量**、**音乐音量**
- **触屏按钮大小**（小 / 中 / 大）

设置保存在这台设备上（不随云存档同步，因为手机和电脑想要的设置往往不同）。

- **改变的决策**：不是玩法决策，而是「这个人能不能、愿不愿意玩下去」
- **为什么值得做**：成本低；对光敏玩家、容易 3D 晕的玩家、手机大拇指偏大的玩家是「能玩 / 不能玩」的区别

## 三、否掉的想法

| 想法 | 为什么不做 |
|---|---|
| 商店 / 行商（用金币买装备） | 买来的装备会削弱打怪掉落的惊喜，和战意（打得好掉得好）冲突 |
| 分解出材料、材料合成 | 多一种资源就多一套换算和背包压力 |
| 拍卖行、交易 | 单机，没有其他玩家 |
| 满级后的无限数值成长 | 只加数值；残光试炼已经给了满级后的目标 |
| 剧情收集品 | 不改变任何决策；以后可以作为世界观内容单独做 |

## 四、需要玩家亲自验证
1. 传承的价格是否合理（太便宜会让强化失去分量，太贵就没人用）
2. 重铸是否让你愿意为一件「差一点」的装备花金币
3. 关掉闪屏和冲击帧后，打击感还剩多少；震屏「弱」是否刚好
4. 手机上大号按钮是否更好按、会不会挡画面
